# Propozycja kategorii kosztów ODM (do Twojej decyzji)

Kategoria to etykieta dla kosztów BEZ eventu (UNASSIGNED) i dla przelewów bez dokumentu; koszty eventowe dostają event, a kategoria mówi tylko „jaki to rodzaj”. Proponuję dwa poziomy: grupa → kategoria.

| Grupa | Kategoria | Przykłady z danych |
| --- | --- | --- |
| Personel eventowy | Hostessy i obsługa (umowa zlecenie) | BLIK dla hostess z arkusza PM |
| Personel eventowy | Podwykonawcy z fakturą (dzieło/B2B) | fotograf, technika |
| Realizacja eventu | Wynajem sali i przestrzeni | sala Odra |
| Realizacja eventu | Catering | catering |
| Realizacja eventu | Technika sceniczna (dźwięk, światło, LED) | Kwadrat nagłośnienie |
| Realizacja eventu | Noclegi i podróże | Hotel Wawel Grand, paragon paliwo |
| Realizacja eventu | Scenografia, druk, materiały | - |
| Realizacja eventu | Transport i logistyka | - |
| Biuro | Czynsz i media biura | czynsz |
| Biuro | Telefonia i internet | 12 faktur Orange |
| Biuro | IT i subskrypcje (SaaS) | Google, Anthropic, Notion |
| Biuro | Leasing i auto | rata leasingu |
| Biuro | Księgowość i doradztwo | biuro rachunkowe |
| Biuro | Marketing i reprezentacja | - |
| Wynagrodzenia i daniny | Wynagrodzenia (agregat) | lista płac |
| Wynagrodzenia i daniny | ZUS | składki |
| Wynagrodzenia i daniny | PIT od umów cywilnoprawnych | zaliczki PIT |
| Podatki i finanse | VAT i inne podatki (US) | VAT-7 |
| Podatki i finanse | Prowizje i opłaty bankowe, odsetki | prowizje |
| Przepływy niekosztowe | Zaliczki i kaucje (do rozliczenia) | zaliczka dla dostawcy |
| Przepływy niekosztowe | Transfery własne | mBank ↔ Millennium, przeksięgowania VAT |
| Przepływy niekosztowe | Zwroty i nadpłaty | zwrot duplikatu |
| Inne | Inne / do wyjaśnienia | - |

Uwaga: ZUS i PIT w v1 idą do UNASSIGNED (Twoja decyzja D9), kategoria jest niezależna od tego.
